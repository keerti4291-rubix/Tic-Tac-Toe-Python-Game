# Project Statement

## Problem Statement
A console Tic Tac Toe game supporting three board sizes and two game modes.

## Scope
3x3, 4x4 and 5x5 boards, Computer vs Player, Player vs Player, input validation, winner detection, draw detection and replay.

## Module Structure
Each board size has its own logic module. Computer vs Player and Player vs Player are separate modules. `main.py` imports all five modules and controls the application.
