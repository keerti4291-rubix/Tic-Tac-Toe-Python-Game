# Tic Tac Toe

Six Python files are used.

- `tic_tac_toe_3x3.py` - 3x3 game logic
- `tic_tac_toe_4x4.py` - 4x4 game logic
- `tic_tac_toe_5x5.py` - 5x5 game logic
- `computer_vs_player.py` - Computer vs Player logic
- `player_vs_player.py` - Player vs Player logic
- `main.py` - imports all five modules and runs the program

Run with:

```bash
python main.py
```
